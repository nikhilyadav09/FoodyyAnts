## 🎯 Overview

FoodyyAnts is a professional restaurant website designed to showcase a fusion cuisine restaurant's menu, ambiance, and services. The website provides information about the restaurant, displays featured dishes, customer reviews, location details, and allows visitors to reserve tables.

**Location:** 123 MG Road, Near City Mall, Bhopal, MP

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nikhilyadav09/FoodyyAnts.git
   cd FoodyyAnts
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     
     # Using Node.js (with http-server)
     npx http-server
     ```

3. **Access the website:**
   - Open `http://localhost:8000` in your browser

## 🎨 Customization

### Update Restaurant Information

**In all HTML files, update:**
- Restaurant name (search for "FoodyyAnts")
- Contact phone number: `+91 9876543210`
- Email: `contact@foodyants.com`
- Address: `123 MG Road, Near City Mall, Bhopal, MP`
- Social media links in footer

### Modify Styling

**In `styles.css`:**
- Color scheme (primary/secondary colors)
- Font sizes and typography
- Layout and spacing
- Responsive breakpoints

### Update Content

**Menu Items:**
- Edit dish names, descriptions, and prices in `menu.html`
- Update featured items in `index.html` (lines 59-89)

**Reviews:**
- Add/edit customer testimonials in `index.html` (lines 146-191)

**Images:**
- Replace `jayantbackground.jpg` with your restaurant's background image
- Update map image URL in location section
